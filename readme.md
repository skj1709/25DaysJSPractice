# 🎯 Guess The Number Game

A simple and fun **JavaScript console game** where you try to guess a random number between **10 and 20** within **3 lives**.  
Perfect for beginners to learn about **loops, conditionals, and random number generation** in JavaScript!

## 🧩 How It Works

1. The computer randomly selects a **target number** between **10 and 20**.
2. You start with **3 lives**.
3. You enter your guess (using the prompt window).
4. If your guess matches the target number:
   - You win 🎉
   - Your remaining lives become your **score**.
5. If your guess is wrong:
   - You lose one life.
   - The game tells you your remaining lives.
6. If you run out of lives before guessing correctly:
   - You lose 😢
   - The correct number is revealed.
